# LifeRPG — Features

## Feature Status

Features are divided into three groups:

- MVP — required for the first playable version.
- V1 — planned after the MVP.
- Future — ideas for later development.

---

# 1. MVP Features

The MVP should demonstrate the core LifeRPG concept:

> Real life → Quest → XP → Skill → Reward → World progression.

---

## 1.1 Character

Status: MVP

The user creates a basic RPG character.

Initial features:

- Character name
- Basic appearance
- Hairstyle
- Skin tone
- Body type
- Basic clothing
- Character level
- XP
- Mood
- Energy

The first version should keep character customization relatively simple.

Advanced customization can be added later.

---

## 1.2 Home Screen

Status: MVP

The home screen is the main screen of the application.

It should show:

- Character
- Current level
- XP progress
- Current quests
- Main goal
- Important progress information
- Access to the player's world

The home screen should immediately communicate:

> "This is my life as an RPG."

---

## 1.3 Quests

Status: MVP

Users can create and complete quests.

Each quest contains:

- Title
- Description
- Category
- Difficulty
- XP reward
- Related skill
- Completion state

Example:

Programming

"Practice React for 30 minutes"

Difficulty: Medium

Reward:

+50 XP
+30 Programming XP

---

## 1.4 Quest Categories

Status: MVP

Initial categories:

- Health
- Fitness
- Education
- Career
- Programming
- Languages
- Finance
- Creativity
- Social
- Hobbies
- Home
- Personal Development
- Travel
- Recovery

Users should eventually be able to customize categories.

---

## 1.5 XP System

Status: MVP

Completed quests provide XP.

XP depends on quest difficulty.

Initial ranges:

Easy:

10–30 XP

Medium:

30–70 XP

Hard:

70–150 XP

Major:

150–500+ XP

The exact progression formula can be adjusted during development.

---

## 1.6 Character Levels

Status: MVP

The character has a global level.

XP contributes to the character's level.

Example:

Level 1
↓
Level 2
↓
Level 3
↓
Level 4

Level progression should provide a clear feeling of growth.

---

## 1.7 Skills

Status: MVP

Users have skills representing different areas of life.

Initial skills:

- Programming
- Languages
- Education
- Career
- Health
- Fitness
- Creativity
- Social
- Finance
- Discipline
- Hobbies
- Travel

Skills gain XP from related quests.

Example:

Programming quest completed.

Result:

+50 Character XP
+30 Programming XP

---

## 1.8 Achievements

Status: MVP

The system tracks meaningful milestones.

Examples:

- First Quest
- First Level Up
- 10 Quests Completed
- 1000 XP Earned
- First Skill Level Up
- First Course Completed
- First Project Completed

Achievements provide rewards such as:

- Badges
- XP
- Titles
- Items

---

## 1.9 Rewards

Status: MVP

Players receive virtual rewards for progression.

Initial reward types:

- Clothing
- Accessories
- Furniture
- Decorations
- Badges
- Titles

The reward system should focus on personalization rather than competitive advantages.

---

## 1.10 Personal World

Status: MVP

The player has a small personal virtual environment.

Initial MVP version:

- One room or small house
- Basic furniture
- Basic decorations
- Character placed inside the environment

Progression can unlock additional items.

The first version does not require a large open world.

---

## 1.11 World Unlocks

Status: MVP

Player progression can unlock simple world elements.

Examples:

Level up:

→ new furniture

Achievement:

→ special decoration

Major milestone:

→ new room

This creates a direct connection between real-life progress and the game world.

---

## 1.12 Goals

Status: MVP

Users can create long-term goals.

Example:

Goal:

"Become a Junior Developer"

Progress:

70%

Related quests:

- Build portfolio
- Study React
- Improve CV
- Practice interview questions
- Apply for jobs

Goals can contain multiple quests.

---

Additional customization:

- More hairstyles
- More clothing
- Accessories
- Different outfits
- Character animations
- Character expressions
- More body customization

---

## 2.2 Inventory

Status: V1

Players can collect and manage items.

Categories:

- Clothing
- Furniture
- Decorations
- Pets
- Accessories
- Special items
- Travel items

Players can unlock virtual pets and companions.

- Exercise
- Walk

Example:

"Improve German"

Possible suggestions:

- Learn 10 new words
- Practice speaking for 15 minutes
- Watch a German video
- Write a short text
- Talk to someone in German

# 3. Future Features

These features are intentionally postponed.

They should not block the MVP.

---

## 3.1 AI Assistant

Status: Future

Possible capabilities:

- Personalized quest generation
- Goal planning
- Progress analysis
- Conversations
- Motivation
- Suggestions
- Story generation
- Personalized challenges

AI should remain optional.

---

## 3.2 AI Life Story

Status: Future

AI could help transform the user's life information into a personal RPG story.

Possible flow:

User enters life events

↓

AI organizes them

↓

Personal timeline

↓

Achievements

↓

Story chapters

↓

Game world elements

---

## 3.3 AI Image Transformation

Status: Future

Users could upload photos of real objects or memories.

Possible flow:

Photo

↓

AI image processing

↓

Game-style object

↓

Inventory

↓

Personal world

This feature requires additional research into image generation and processing.

---

## 3.4 Real-Life Memory Collection

Status: Future

Users could collect memories as digital game objects.

Examples:

- Photos
- Certificates
- Souvenirs
- Important objects
- Travel memories

---

## 3.5 Open World

Status: Future

The personal room could eventually grow into a larger world.

Possible areas:

- House
- Neighborhood
- City
- Nature
- Shops
- School
- University
- Workplace
- Travel locations

---

## 3.6 Career System

Status: Future

Career development could become a separate RPG progression system.

Possible elements:

- Education
- Courses
- Certificates
- Skills
- Resume
- Job applications
- Interviews
- Career levels

Example:

Junior Developer

↓

Developer

↓

Mid-level Developer

↓

Senior Developer

## 3.7 Finance System

Status: Future

Possible features:

- Savings goals
- Budget
- Financial quests
- Saving achievements
- Financial skill

## 3.8 Health and Fitness Integration

Possible integrations:

- Step tracking
- Workout tracking
- Water tracking
- Sleep information
- Fitness achievements

The application should avoid presenting itself as a medical product.

---

## 3.9 Social Features

Possible features:

- Friends
- Shared challenges
- Multiplayer quests
- Friendly competitions
- Gifts
- Shared events

Social functionality should be carefully designed around privacy and safety.

---

## 3.10 Seasonal Events

Status: Future

Possible seasonal content:

- Winter
- Halloween
- Spring
- Summer
- Special events

Seasonal content may provide:

- Items
- Decorations
- Quests
- Pets

---

## 3.11 Communication Styles

Status: Future

Users may be able to select different communication themes for the application.

Examples:

- Fantasy
- Magical
- Funny
- Cozy
- Retro RPG
- Adventure

The system could change the wording of notifications and messages according to the selected theme.

Example:

Normal:

"New quest available."

Fantasy:

"A new adventure awaits."

---

# 4. Features That Are NOT Part of the MVP

The following should explicitly remain outside the first version:

- AI image generation
- Open world
- Social network
- Real-time multiplayer
- Complex economy
- Advanced travel system
- Geolocation-based gameplay
- Health device integrations
- Financial integrations
- Complex AI assistant
- Automatic life-story generation
- Automatic real-world object recognition

These features may be explored later.

---

# 5. MVP Success Criteria

The MVP should be considered successful if a user can:

1. Create a character.
2. See their character.
3. Create a quest.
4. Complete a quest.
5. Receive XP.
6. Increase a skill.
7. Level up.
8. Unlock an achievement.
9. Receive a reward.
10. See the reward in their personal world.

The complete gameplay loop should feel understandable and satisfying.

---

# 6. Product Principle

The most important feature of LifeRPG is not the number of features.

The most important feature is the connection between real life and game progression.

The player should be able to look at their character and world and think:

> "This is the result of what I have actually done in my life."
